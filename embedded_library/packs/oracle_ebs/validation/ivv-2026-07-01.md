# Oracle E-Business Suite normalized JSON relay IVV — 2026-07-01

## Scope reviewed

Independent verification and validation review for the `oracle_ebs` SecHub Resources pack change that adds a conservative normalized JSON relay parser, Splunk knowledge objects, synthetic-equivalent fixtures, and an Oracle May/June 2026 advisory-focused dashboard.

## Positive findings

- Pack remains conservative: `quality_status=curated`, `trust_level=unverified`, and `validation_harness.status=blocked`.
- The SC4S parser route requires all of `vendor=oracle`, `product=e_business_suite`, `source_mode=ebs_security_json_relay`, and an `ebs_*` event family before assigning `sourcetype=oracle:ebs:security:json`.
- Splunk props use search-time JSON extraction and helper EVALs; no index-time lossy rewrite or default field drop is shipped.
- Fixture corpus contains 15 unique synthetic-equivalent JSON events across 12 declared EBS event families; three families intentionally have two events for warning/error or success/failure coverage.
- Dashboard SPL is scoped to `sourcetype="oracle:ebs:security:json"` and `source_mode="ebs_security_json_relay"`, then runs `spath` before using JSON fields.
- Research note summarizes Oracle/third-party advisory context without storing copied article body text.
- Secret scan and targeted static checks did not find obvious credentials/tokens in the new Oracle EBS artifacts.

## IVV concerns and disposition

| Concern | Disposition |
|---|---|
| Native EBS source shapes are not validated. | Explicitly blocked in README, pack metadata, validation preflight, dashboard gap state, and source delivery status. |
| May/June 2026 advisory panels could be mistaken for exploit detections. | Dashboard description, README, research note, and pack metadata state operator triage only / not exploit detection. |
| Synthetic fixtures could be mistaken for customer or Oracle samples. | Fixtures use `SYNTH_` values and `SC4S_ORACLE_EBS_TEST_` markers; provenance says synthetic-equivalent only. |
| Sensitive business data reduction might be unsafe. | Reduction guidance ships no default drops and requires local replay/read-back before masking. |
| Website publication could over-promote trust. | Generated catalogue preserves curated/unverified and blocked read-back posture from the pack. |
